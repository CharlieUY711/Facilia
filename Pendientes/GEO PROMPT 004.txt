# PROMPT GEO-04 — Agente Móvil / PWA de Captura GPS

> **Rol**
>
> Actúa como un **Senior Mobile Workforce Architect** especializado en Progressive Web Apps (PWA), aplicaciones móviles empresariales, geolocalización, sincronización offline, consumo eficiente de batería y sistemas Field Service Management (FSM).
>
> El módulo **GEO — Geopositioning & Workforce Control** ya cuenta con:
>
> * GEO-00 — Documento funcional y arquitectura.
> * GEO-01 — Modelo de dominio.
> * GEO-02 — Backend Core y APIs.
> * GEO-03 — Integración con Directory y Operations.
>
> Esta etapa implementa el componente móvil encargado de capturar ubicación de los colaboradores.
>
> **No desarrollar aplicación nativa Android/iOS.**
>
> **No implementar mapas.**
>
> **No implementar optimización de rutas.**
>
> La solución debe ser una **PWA empresarial** preparada para funcionar en celulares provistos por FACILIA.

---

# Objetivo

Crear un agente móvil que permita:

* identificar al empleado;
* vincular el dispositivo;
* iniciar sesión operativa;
* capturar ubicación;
* enviar posiciones al backend GEO;
* funcionar con conectividad limitada.

---

# Principio fundamental

El dispositivo no es el dueño de la información.

El dispositivo solamente captura.

El backend GEO es la fuente de verdad.

---

# Plataforma

Implementar como:

* Progressive Web App.
* Responsive.
* Mobile First.

Preparada para:

* Android corporativo;
* Chrome Mobile;
* instalación como aplicación.

# Captura GPS

Implementar captura periódica.

Registrar:

* latitud;
* longitud;
* precisión;
* timestamp;
* estado conexión.

---

# Frecuencia configurable

No fijar valores rígidos.

Permitir configuración:

Ejemplo:

* cada 1 minuto;
* cada 5 minutos;
* cada 15 minutos.

La configuración debe venir del backend.

# Optimización de batería

* evitar GPS permanente;
* aumentar intervalo cuando no hay movimiento;
* enviar paquetes agrupados;
* utilizar sincronización inteligente.

# Funcionamiento Offline

Implementar almacenamiento local.

Cuando no existe conexión:

Guardar:

* ubicaciones pendientes;
* timestamps;
* sesión activa.

Al recuperar conexión:

Sincronizar automáticamente.
