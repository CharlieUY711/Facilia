# Objetivo

Implementar la capa backend que permita:

* enviar mensajes WhatsApp;
* recibir mensajes;
* procesar webhooks;
* registrar estados de entrega;
* mantener conversaciones;
* abstraer el proveedor externo.

---


# Principio fundamental

Twilio NO pertenece al dominio.

Debe existir un adaptador.

Arquitectura:

```text id="qz7l4x"
COM Domain

      |

CommunicationProvider Interface

      |

Twilio WhatsApp Adapter

      |

Twilio API
```
