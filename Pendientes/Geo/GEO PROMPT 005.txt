# PROMPT GEO-05 — Motor de Geocercas y Validaciones Operativas

> **Rol**
>
> Actúa como un **Enterprise Software Architect** especializado en Geospatial Computing, Location Intelligence, Field Service Management (FSM), Workforce Management, motores de reglas y Clean Architecture.
>
> El módulo **GEO — Geopositioning & Workforce Control** ya cuenta con:
>
> * GEO-00 — Documento funcional y arquitectura.
> * GEO-01 — Modelo de dominio y persistencia.
> * GEO-02 — Backend Core y APIs.
> * GEO-03 — Integración con Directory y Operations.
> * GEO-04 — Agente Móvil / PWA de captura GPS.
>
> Esta etapa implementa el motor encargado de interpretar posiciones GPS y convertirlas en eventos operativos.
>
> **No desarrollar mapas avanzados.**
>
> **No desarrollar optimización de rutas.**
>
> **No desarrollar IA.**
>
> El objetivo es implementar validaciones geográficas operativas básicas y confiables.

---

# Objetivo

Transformar datos GPS en información operacional:

```text
Ubicación GPS

+

Geocerca

+

Horario

+

Orden asignada

↓

Evento operativo
```

---

# Principio fundamental

El GPS solo proporciona posición.

El motor GEO interpreta esa posición.

Ejemplo:

GPS:

```text
Latitud: X
Longitud: Y
```

Motor GEO:

```text
Empleado llegó al cliente
```

---

# Alcance MVP

Implementar:

* creación de geocercas;
* cálculo de distancia;
* detección entrada;
* detección salida;
* permanencia;
* validación contra órdenes;
* alertas básicas.

---

# Modelo de Geocerca

Una geocerca representa una zona autorizada.

Ejemplos:

* cliente;
* oficina;
* depósito.

---

# Tipos iniciales

```text
CLIENT_LOCATION

OFFICE

WAREHOUSE

CUSTOM
```

---

# Configuración

Cada geocerca debe permitir:

* nombre;
* organización;
* ubicación;
* radio;
* estado;
* referencia externa.

---

# Cálculo geográfico

Implementar cálculo de distancia entre:

```text
posición actual

vs

centro de geocerca
```

Utilizar fórmula geográfica adecuada.

Ejemplo:

Haversine.

---

# Estados de presencia

Crear máquina de estados:

```text
OUTSIDE

ENTERING

INSIDE

LEAVING
```

---

# Eventos

Generar:

## Entrada

Cuando:

```text
Distancia <= Radio permitido
```

Evento:

```text
EmployeeArrivedLocation
```

---

## Salida

Cuando:

```text
Distancia > Radio permitido
```

Evento:

```text
EmployeeLeftLocation
```

---

## Permanencia

Mientras:

```text
Estado = INSIDE
```

Registrar:

* inicio;
* fin;
* duración.

Evento:

```text
EmployeeStayedLocation
```

---

# Anti falsos positivos

Implementar controles básicos:

## Precisión GPS

No aceptar ubicaciones con precisión insuficiente.

Ejemplo:

GPS error > radio permitido.

---

## Persistencia mínima

No generar entrada/salida con un único punto.

Validar:

* repetición;
* continuidad;
* timestamps.

---

## Movimiento

Preparar para detectar:

* estático;
* desplazamiento.
