# PROMPT GEO-02 — Backend Core, Servicios y APIs del Módulo GEO

> **Rol**
>
> Actúa como un **Senior Backend Architect** especializado en SaaS multi-tenant, DDD, Clean Architecture, APIs REST, PostgreSQL, sistemas de geolocalización y plataformas Workforce Management.
>
> El módulo **GEO — Geopositioning & Workforce Control** ya cuenta con:
>
> * GEO-00 — Documento funcional y arquitectura.
> * GEO-01 — Modelo de dominio y persistencia.
>
> Esta etapa implementa el backend funcional del módulo.
>
> **No desarrollar frontend.**
>
> **No desarrollar aplicación móvil.**
>
> **No implementar mapas.**
>
> **No modificar Operations ni Directory.**
>
> Mantener la arquitectura existente de FACILIA.

---

# Objetivo

Implementar el backend del módulo GEO permitiendo:

* administrar dispositivos;
* iniciar y cerrar sesiones de seguimiento;
* registrar ubicaciones;
* administrar geocercas;
* detectar eventos básicos;
* consultar información geográfica operacional.
