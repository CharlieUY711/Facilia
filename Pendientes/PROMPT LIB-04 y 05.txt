# Objetivo

Implementar un sistema profesional de **versionado documental** que permita conservar la historia completa de cada documento.

Un documento nunca debe perder información histórica.

Cada modificación debe generar una nueva versión.

---

# Concepto

Separar:

## Documento lógico

Representa la entidad documental.

Ejemplo:

```
Manual de Limpieza Industrial
```

---

## Versiones

Representan sus estados históricos.

Ejemplo:

```
Manual de Limpieza Industrial

v1
Creado 01/01/2026

v2
Actualizado 15/03/2026

v3
Actualizado 20/06/2026
```

---

# Funcionalidades

Implementar:

## Crear versión

Cuando un documento cambia:

* conservar versión anterior;
* almacenar nuevo archivo;
* incrementar versión;
* registrar autor;
* registrar fecha.

---

## Historial

Mostrar:

* número de versión;
* fecha;
* usuario;
* comentario;
* tamaño;
* estado.

---

## Comparación

Preparar arquitectura para:

* comparación de metadatos;
* comparación futura de contenido.

---

## Restauración

Permitir:

```
Versión actual v3

Restaurar v2

Resultado:

Nueva versión v4 basada en v2
```

Nunca eliminar historial.

---

# Modelo de datos

Crear:

Campos mínimos:

* id

* version_number
* storage_path
* file_size
* checksum

* comment
* created_at
