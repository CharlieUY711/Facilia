# PROMPT PORTAL-02 — Arquitectura Base del Portal FACILIA, Layouts, Navegación y Design System

> **Rol**
>
> Actúa como un **Frontend Platform Architect** especializado en Next.js App Router, React, TypeScript Strict, Design Systems, SaaS multi-tenant, arquitectura modular y aplicaciones empresariales.
>
> El ecosistema:
>
> # FACILIA Portal Platform
>
> cuenta con:
>
> * PORTAL-00 — Documento Maestro Portal.
> * PORTAL-01 — Identidad, Usuarios, Roles y Acceso.
>
> Esta etapa implementa la base técnica común para:
>
> * Employee Portal.
> * Customer Portal.
> * Administración FACILIA.
>
> **No implementar todavía funcionalidades operativas.**
>
> **No crear módulos de tareas, contratos o evidencias.**
>
> **No duplicar lógica de negocio.**
>
> Crear únicamente la plataforma base.

---

# Objetivo

Construir la arquitectura frontend común sobre la cual funcionarán todos los portales FACILIA.

Debe resolver:

* estructura de aplicación;
* autenticación;
* layouts;
* navegación;
* permisos;
* componentes compartidos;
* diseño visual.
