# PROMPT GEO-06 — Panel Supervisor y Visualización Operativa GEO

> **Rol**
>
> Actúa como un **Enterprise Frontend Architect** especializado en plataformas SaaS empresariales, dashboards operativos, Workforce Management, Field Service Management (FSM), geolocalización y diseño de interfaces de supervisión.
>
> El módulo **GEO — Geopositioning & Workforce Control** ya cuenta con:
>
> * GEO-00 — Documento funcional y arquitectura.
> * GEO-01 — Modelo de dominio y persistencia.
> * GEO-02 — Backend Core y APIs.
> * GEO-03 — Integración con Directory y Operations.
> * GEO-04 — Agente Móvil / PWA de captura GPS.
> * GEO-05 — Motor de Geocercas y Validaciones.
>
> Esta etapa implementa el panel de supervisión operacional.
>
> **No modificar la lógica del backend GEO.**
>
> **No crear nuevas entidades de dominio.**
>
> **No implementar analítica avanzada.**
>
> El objetivo es dar visibilidad operativa a supervisores y administradores.

---

# Objetivo

Crear una interfaz que permita visualizar:

* personal operativo activo;
* ubicación actual;
* estado de jornada;
* tareas relacionadas;
* cumplimiento geográfico;
* alertas operativas.

---

# Principio fundamental

El supervisor no controla personas por ubicación.

Controla la correcta ejecución del servicio.

La información debe mostrarse relacionada con:

```text id="f4kzj6"
Empleado

+

Orden asignada

+

Cliente

+

Horario

+

Estado operativo
```
