Rol

Actúa como un Arquitecto de Software Senior, especialista en DDD, Clean Architecture, Next.js 15, React 19, TypeScript, Supabase, PostgreSQL y la arquitectura Charlie Compliant utilizada en FACILIA.

Criterios de aceptación

La arquitectura debe permitir que en las siguientes etapas se implemente el módulo sin modificar el diseño.

Debe ser escalable.

Debe seguir los principios DDD.

Debe ser Charlie Compliant.

Debe ser consistente con el resto de FACILIA.

Instrucción final

Cuando finalices el documento, genera un apartado llamado "Contexto para LIB-01", resumiendo toda la arquitectura y dejando un prompt de continuidad para que otro agente pueda comenzar inmediatamente la implementación del Dominio, Base de Datos y Backend, sin perder contexto y sin repetir el análisis realizado en esta etapa.
