# ACL (Access Control List)

Implementar una arquitectura desacoplada para permisos.

Crear las tablas necesarias.

Como mínimo:

## library_acl

Debe permitir asignar permisos a:

* Usuario
* Rol
* Organización

Permisos soportados:

* READ
* WRITE
* DELETE
* SHARE
* OWNER

Cada documento podrá tener múltiples reglas.

No hardcodear permisos.

Utilizar enums y Value Objects.

# Criterios de aceptación

Al finalizar:

* Library debe funcionar completamente.
* Debe existir repositorio Público y Privado.
* Deben funcionar los permisos básicos mediante ACL.
* Debe existir auditoría de acciones.
* Debe poder compartirse un documento con usuarios, roles y organizaciones.
* Debe existir un servicio transversal para asociar documentos a cualquier entidad del sistema.
* Todo debe compilar sin errores.
* Todo debe respetar la arquitectura Charlie Compliant.

# Instrucción final

Antes de finalizar:

1. Ejecuta una revisión completa del módulo.
2. Corrige automáticamente cualquier inconsistencia detectada.
3. Elimina código duplicado o innecesario.
4. Verifica que el módulo compile completamente.
5. Lista todos los archivos creados o modificados.
6. Genera un documento **LIBRARY-README.md** con la documentación funcional y técnica del módulo.
7. Genera un apartado **"Preparado para Fase 2"** describiendo qué componentes y puntos de extensión quedaron listos para incorporar, en futuras iteraciones:

   * Versionado de documentos.
   * Gestión de contratos.
   * Firma electrónica.
   * OCR.
   * Indexación y búsqueda semántica.
   * Flujos de aprobación.
   * Integración con IA.

**No implementes esas funcionalidades; únicamente deja el módulo preparado para evolucionar sin cambios de arquitectura.**
